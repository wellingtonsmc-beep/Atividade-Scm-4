# Atividade SCM U4 — Gerenciamento de Configuração

Repositório acadêmico da atividade prática da Unidade U4 — Projeto de Software Avançado, Aula A1 — Gerenciamento de Configuração.

## Objetivo
Demonstrar a organização e o controle de artefatos de um projeto de software utilizando Git e GitHub.

## Artefatos
- `novo.py`: exemplo de artefato Python inicial.
- `nova_funcionalidade.py`: exemplo de funcionalidade adicionada.
- `documentacao.md`: registro das etapas e dos comandos utilizados.

## Fluxo da atividade
1. Criar o repositório remoto no GitHub.
2. Clonar o repositório para o computador com `git clone`.
3. Criar ou modificar artefatos localmente.
4. Conferir alterações com `git status`.
5. Preparar alterações com `git add .`.
6. Registrar alterações com `git commit`.
7. Publicar no GitHub com `git push`.

> Observação: os arquivos deste repositório foram preparados diretamente no GitHub. Para comprovar as etapas locais exigidas no roteiro, execute os comandos no computador e registre capturas reais do terminal.
