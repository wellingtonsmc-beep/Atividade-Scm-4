- Unidade: U4 — Projeto de Software Avançado
- Aula: A1 — Gerenciamento de Configuração

## Artefatos do projeto
- `novo.py`: apresenta o projeto.
- `nova_funcionalidade.py`: contém uma função adicional para demonstrar a criação de um artefato.

## Comandos previstos no roteiro

```bash
git config --global user.name "Seu Nome"
git config --global user.email "seu-email@example.com"
git clone https://github.com/wellingtonsmc-beep/Atividade-Scm-4.git
cd Atividade-Scm-4
git status
git add .
git commit -m "Adiciona e atualiza artefatos"
git push origin main
```

## Evidências
As capturas de tela devem ser feitas durante a execução real no computador:
1. Configuração do Git.
2. Clonagem do repositório.
3. Arquivos na pasta local.
4. Resultado de `git status`.
5. Execução de `git add` e `git commit`.
6. Execução de `git push`.
7. Arquivos e commits visíveis no GitHub.

Não registrar como executado nenhum comando que ainda não tenha sido realizado localmente.
